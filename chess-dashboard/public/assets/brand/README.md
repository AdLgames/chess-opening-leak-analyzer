# Opening Leak Lab artwork

The knight and rising move-path mark is original SVG artwork created for this
project. `mark.svg` is the app icon; `wordmark.svg` is the horizontal lockup.

`coaches.webp` is original generated artwork made for this project on 17 October
2026. Maya, Theo and Inez are fictional illustrated guides, not real coaches or
credentialled chess professionals. The three equal-width columns are displayed
using CSS background positioning; no third-party character artwork is used.
The existing authored lesson text and verified engine explanations remain the
source of chess feedback, regardless of the character a player selects.
