# Static teaching boards

Generated by `chess_opening_analyzer/tools/build_public_diagrams.py`, using
python-chess to replay legal lines and render SVG boards. This project supplies
the board colours, arrows, circles and captions.

The static SVG piece artwork is by **Colin M. L. Burnett (Cburnett)**, as included
in python-chess. The upstream renderer is distributed under GPL-3.0-or-later;
these generated static SVG assets are distributed under that licence. The full
licence is in [COPYING.txt](COPYING.txt). Each SVG includes an attribution notice.

- Renderer and embedded piece source: <https://github.com/niklasf/python-chess/blob/master/chess/svg.py>
- Upstream attribution: <https://github.com/niklasf/python-chess/blob/master/docs/svg.rst>
- Author: <https://en.wikipedia.org/wiki/User:Cburnett>

The live interactive board continues to use the project's original piece art in
`app/board.js`; this attribution concerns the six static fallback/guide boards.
