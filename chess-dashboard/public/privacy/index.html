Privacy & your data

Start with a lesson. Keep control of what you save.

Last updated: 17 October 2026. This page describes the hosted website at chessleaklab.co.uk, an independent project maintained by AdLgames. For product and data questions, see Contact.

Browsing and guest learning

Public course previews run in your browser and do not submit game analysis or create a learning attempt. Guest repertoire entries, learning checkpoints, recall history, the most recent report and preferences are stored in browser storage when available. Someone using the same browser profile may be able to see that working copy. If storage is blocked, the app explains that progress may last only in the current tab.

Accounts and essential storage

Signing in uses an essential session cookie. The server stores a hash of the random session token, not the token itself. Email sign-in stores the email address; Lichess sign-in stores the provider identity and username. The Lichess sign-in access token is used to identify the account and is not retained by the current sign-in flow.

When signed in, the service stores account progress, repertoire choices, preferences, learning events, analysis history and the most recent report in the deployment’s database. Game identifiers and decision evidence allow analysis to accumulate without counting the same game twice. These records remain until you delete the account or the associated saved material.

When you ask for game analysis

The hosted server fetches the public Chess.com or Lichess archive you request, or receives the PGN you upload, and analyses it on the server. Archive content is processed in temporary storage, which may remain until the server instance is recycled. Saved reports and evidence are separate from those temporary archives. Do not upload games or notes you do not want processed by the hosted service.

Chess.com or Lichess receives the requested archive lookup. The hosting provider handles normal web requests and may retain operational logs, including network information, under its own policies. Email sign-in, when enabled, uses the configured transactional-email provider. The app’s source is available if you prefer to run analysis locally.

Optional usage counts

Optional usage measurement is off unless the site operator enables a provider and you choose to allow it. Learning works without it.

When enabled and allowed, counts cover page views, public lesson starts and completions, course openings and completed training sessions. They contain a fixed public page path and coarse course or session labels. They do not include chess usernames, query strings, game moves, FENs, emails, account IDs or a stored analytics identifier. The analytics provider still receives network information needed to process the request.

Global Privacy Control and Do Not Track keep optional measurement off. If browser storage is unavailable, the preference lasts only for this page. You can change your choice here. The optional provider is Plausible; read its data policy.

Download, delete and sign out

Use Download my data in the workspace account menu to export saved account information as JSON. Delete my account removes the account and its associated database records. Browser downloads and exports you made yourself are outside that deletion. Hosting or delivery logs follow their provider’s retention policies.

Signing out clears the app’s local account working copy, but does not delete the server account. Browser site-data controls can remove guest storage. Keep a repertoire export before clearing local-only work you want to retain.
